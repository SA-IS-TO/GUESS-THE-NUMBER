# 🎮 Guess The Number Game (C++)

A simple number guessing game built using C++.

## ✨ Features
- Random number between 1 and 100
- Higher and Lower hints
- Unlimited guesses until correct
- Counts total attempts

## 🛠️ Technologies
- C++
- iostream
- cstdlib
- ctime

## ▶️ How to Run
1. Compile the main.cpp file.
2. Run the program.
3. Guess the secret number between 1 and 100.
4. Follow the Higher or Lower hints.
